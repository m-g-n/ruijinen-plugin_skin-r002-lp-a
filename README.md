# 類人猿 Snow Monkeyスキン LPパターン用
LPパターン（R002）向けのSnow Monkeyスキンです

## このプラグイン動作の前提条件
- Snow Monkeyテーマがインストールされてない環境では動きません

# 開発環境
- Node.js 24（バージョンは `mise.toml` で管理。mise を使う場合は `mise install` で導入）

# SCSSのコンパイル方法
当プラグインディレクトリーまで移動したあと、

- npm ci でpackageをインストール
- npm run watch でSCSSファイルの修正を常時監視（SCSSを修正したら即時CSSにコンパイルしてくれる）
- npm run build でCSSにコンパイル（コマンド走ったときだけCSSをコンパイル）

## composerのインストール方法
当プラグインディレクトリーまで移動したあと、

- composer install でパッケージをインストール

# リリース方法
- プラグインのルートファイル（`ruijinen-skin-r002-lp.php`）の `Version:` を更新し、この README の「変更履歴」に `## <バージョン>` の項目を追加する
- dev にマージすると、そのバージョンをタイトルにしたリリース PR（dev → main）が作成・更新される
  - 本文には変更履歴の該当バージョンの内容と、含まれるプルリクエストの一覧が自動で入る（本文はマージのたびに上書きされるため、手動での編集は残らない）
  - リリース PR の本文は、そのまま GitHub Release のリリースノートになる
- リリース PR を main にマージすると、ルートファイルのバージョンでタグ・GitHub Release・配布用 zip が作成される
  - 同じバージョンのリリースが既に存在する場合はリリース作成をスキップする
